# Aayan Amir — Portfolio

An interactive portfolio set inside a calm orbital workshop.

## Planned experience

- Explore a 3D workshop from an anchored camera position.
- Select objects to discover projects, experience, and contact information.
- Access the same information through clear navigation and an accessible text view.

Planned stack: Astro, TypeScript, React, and React Three Fiber / Three.js.

Status: planning complete; implementation has not started.
