# Workshop places and interactions

24 October 2026. The user identified both layout and lack of interaction as the principal problems. This pass focuses on those, retaining the colorful illustrated models and existing planet rendering.

## Spatial changes

The room now has three connected work areas: a side library cabinet for Student Portal, a smaller central NoClash worktable, and a separate angled NoTerm tool bench. Resume/contact have a side cabinet rather than overlapping the command press. All projects remain mounted in the same scene. Rotation reveals the side areas; no tabs swap project models.

## Interactions

Selecting a project starts a short physical illustration and opens a compact non-modal preview:

- NoClash: a sample row moves into alignment, the handwheel turns and the shuttle travels across.
- Student Portal: a selected book slides out and the open resource tilts into view.
- NoTerm: the confirmation key depresses, the crank turns and paper advances.

Each has a specifically named replay action. Full case studies are available immediately from the preview, or directly through the Work index; no animation or game gates reading. These are illustrations of the projects' workflows, not running versions of their applications. The command press executes no system commands.

Only the selected mechanism animates. Frame time is clamped after interruptions, and the demand renderer stops once motion settles. Reduced/still modes show the settled state immediately. Reading a case study pauses decorative movement. Switching projects cancels the previous illustration and resets its model. Replaying resets the active sequence.

Preview headings receive focus; Escape/close return it to the origin. Dialog close falls back to the persistent Work control if the originating preview button was removed. Phone look controls sit within the preview heading so they do not cover the mechanism or block exploration.
