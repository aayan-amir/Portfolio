# Closer workshop composition

24 October 2026. Revision following feedback that the colorful room still felt weird and boring.

The earlier room placed three equally staged objects along a counter beyond a large open floor. This pass changes the spatial composition rather than adding another color palette.

- Lower/closer anchored camera and a nearer working table create foreground, middle and background layers.
- The timetable loom and command press occupy different positions/angles on a full-depth wood worktable.
- The library sits on a cabinet farther back, visible between the foreground instruments.
- Notebook, warm lamp, upholstered reading seat and textured cushions create a separate personal corner.
- A pulled-out stool, papers, pencil, mug and thread spools suggest ongoing work without adding more hotspots.
- Original procedural wood-grain and linen textures give large surfaces material variation. Owned textures are disposed on unmount.
- Static contact shadows and local tabletop contact patches replace the long hard shadows. Floor shadow capture renders once and remains quiet at rest.
- Smaller nameplates retain all object names; details appear on hover/focus. Objects remain selectable directly or through native HTML controls.
- Camera signs, fixed-position rotation, all project content, current planetary rendering and destination selection are preserved.

The remaining subjective uncertainty is whether the user's dissatisfaction is principally the illustrated/toy-like rendering style, the room layout or the lack of interesting interaction. A preference question was asked while the spatial revision was built. This pass does not claim to resolve that preference before the user answers.

Verification: type check and production build pass; eleven camera/navigation tests pass. Desktop visual review caught and corrected a project-overlap problem. Phone-sized layout and object routes are checked separately from physical phone GPU performance. The shader/image/material assets remain stylized real-time rendering rather than an offline concept render.
